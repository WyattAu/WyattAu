# WyattAu

Personal projects and open-source crates by Wyatt Au.

## Major Projects

### Ferro
Full-featured file synchronization server with WebDAV, CalDAV, CRDT, and WASM plugin support.
- **Language:** Rust
- **License:** AGPL-3.0
- **Features:** WebDAV, CalDAV, CRDT sync, WASM plugins, multi-tenant, federation, ActivityPub, WebRTC

### Suture
Patch-based version control system with semantic merge and format-aware drivers.
- **Language:** Rust
- **License:** AGPL-3.0
- **Features:** Semantic merge, format-aware drivers (DOCX, XLSX, PPTX, PDF, HTML), Raft consensus, TUI

### CrawlKit
Rust web crawler and SEO analysis toolkit with extensible analyzers and WASM plugin system.
- **Language:** Rust
- **License:** Apache-2.0
- **Features:** Web crawling, SEO analysis, WASM plugins, Redis caching, PostgreSQL storage

### Pediment
SolidJS component library and design system.
- **Language:** TypeScript
- **License:** MIT/Apache-2.0
- **Features:** UI components, theming, documentation, Storybook

### WyattsNotes
Multi-site educational documentation platform covering A-Levels, IB, DSE, GCSE, and more.
- **Language:** TypeScript
- **License:** AGPL-3.0
- **Features:** Docusaurus + Starlight, Algolia search, multi-site architecture
